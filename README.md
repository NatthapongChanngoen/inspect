# ระบบตรวจสอบการทำงาน แม่บ้าน / รปภ.

เว็บแอป (PWA ใช้บนมือถือได้) สำหรับ **ควบคุมและตรวจสอบการทำงาน** ของแม่บ้านและ รปภ. ที่ทำงานตามจุดต่างๆ ในแต่ละสถานที่
แก้ปัญหา “พนักงานมาทำงานจริงไหม ตรงจุดไหม งานเรียบร้อยไหม” ด้วยการ **เช็คอินด้วย QR + GPS → ถ่ายรูปก่อน/หลังทำงาน → ให้ผู้ตรวจอนุมัติผ่าน/ไม่ผ่าน** พร้อมเก็บวัน-เวลาทุกขั้นตอน

---

## 👥 ผู้ใช้ 3 บทบาท
| บทบาท | หน้าที่ |
|-------|---------|
| **พนักงาน** (STAFF) | เช็คอินทำงาน ถ่ายรูป ส่งงาน ดูประวัติของตัวเอง |
| **ผู้ตรวจสอบ** (INSPECTOR) | ตรวจงานที่ส่งมา อนุมัติผ่าน/ไม่ผ่าน |
| **ผู้ดูแลระบบ** (ADMIN) | จัดการสถานที่/จุด/ผู้ใช้ มอบหมายงาน ดูแดชบอร์ด/รายงาน |

---

## ⭐ ฟีเจอร์หลัก

### พนักงาน
- เห็นงานที่ได้รับมอบหมายวันนี้
- **เช็คอิน**: สแกน QR ที่จุด + ยืนยันพิกัด GPS (ต้องอยู่ในรัศมี) + ถ่ายรูปก่อนทำงาน
- ทำงานเสร็จ → ถ่ายรูปหลัง → ส่งงาน
- ดูประวัติงาน + ผลตรวจของตัวเอง
- สมัครสมาชิกเองได้ (`/register`) → ได้บทบาทพนักงานอัตโนมัติ

### ผู้ตรวจสอบ
- คิวงานรอตรวจ (มีป้าย “น่าสงสัย” ถ้าระบบจับได้)
- ดูรูปก่อน/หลัง + พิกัดบนแผนที่ + เวลา
- **อนุมัติ 2 แบบ** (เลือกได้ต่องาน):
  1. **ดูรูประยะไกล** — ดูหลักฐานแล้วกดผ่าน/ไม่ผ่าน
  2. **ไปตรวจที่จุดจริง** — สแกน QR + GPS + ถ่ายรูป ณ จุด แล้วกดผ่าน/ไม่ผ่าน
- ใส่หมายเหตุได้ → อัปเดตสถานะ `APPROVED` / `REJECTED`

### ผู้ดูแลระบบ
- **แดชบอร์ด** สรุปงานวันนี้ (กำลังทำ / รอตรวจ / ผ่าน / ไม่ผ่าน) + แจ้งเตือนงานน่าสงสัย
- จัดการ **สถานที่ · จุดเช็คอิน · ผู้ใช้** — เพิ่ม / แก้ไข / ปิดใช้งาน / ลบ (มีการกันลบถ้ามีประวัติงาน)
- จุดเช็คอิน: **เลือกพิกัดบนแผนที่** (Leaflet) หรือใช้ตำแหน่งปัจจุบัน + **พิมพ์ QR** ไปติด
- **มอบหมายงาน** ให้พนักงานรายวัน
- **รายงานเวลาทำงาน** (`/admin/reports`) — พนักงานใช้เวลากี่นาทีต่อจุด (เช็คอิน → ส่งงาน) กรองตามคน/จุด/วันได้
- **รายการน่าสงสัย** — งานที่อาจปลอมตำแหน่ง (fake GPS)

---

## 🛡️ ระบบกันโกง (ครบชุด — QR ยังพิมพ์คงที่ ไม่ต้องเปลี่ยนรายวัน)
1. **QR ต้องตรงจุด** — token ใน QR ต้องตรงกับจุดที่เช็คอิน
2. **GPS ต้องอยู่ในรัศมี** ของจุด (คำนวณระยะแบบ Haversine)
3. **ความแม่นยำ GPS ≤ 50 ม.** (ปรับได้) — กันพิกัดหยาบจาก wifi/ปลอม
4. **รหัสเซสชันใช้ครั้งเดียว อายุ 5 นาที (nonce)** — กันการยิง request เดิมซ้ำ
5. **เช็คอินซ้ำจุด/วันไม่ได้** (ยกเว้นของเดิมถูกตีกลับ)
6. **ถ่ายรูปสดจากกล้องเท่านั้น** — เลือกรูปเก่าจากคลังไม่ได้
7. เก็บ **IP / อุปกรณ์ / เวลา** ทุกขั้น + **ตั้งธงงานน่าสงสัย** ให้ผู้ตรวจดู

## 🧰 เทคโนโลยี
- **Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS** — เว็บ + API + admin ในโปรเจคเดียว
- **PostgreSQL + Prisma** — ฐานข้อมูล
- **Auth.js (NextAuth v5)** — ล็อกอิน username/password + แบ่งสิทธิ์ 3 บทบาท (ผ่าน middleware)
- **UI:** ไอคอน `lucide-react`, ฟอนต์ `Prompt`, แผนที่ `Leaflet + OpenStreetMap`, QR ด้วย `qrcode` (สร้าง) + `@zxing/browser` (สแกน)
- **รันด้วย Docker:** `app` (Next.js) + `db` (Postgres) + `adminer` + `cloudflared` (Cloudflare Tunnel)
- เก็บรูปใน Docker volume เสิร์ฟผ่าน `/api/files/...` (ต้องล็อกอิน) — สลับไป MinIO/S3 ภายหลังได้โดยแก้ `src/lib/storage.ts`

## 🚀 วิธีรัน (ใช้ Docker อย่างเดียว — ไม่ต้องติดตั้ง Node)

```bash
# มีไฟล์ .env ให้แล้ว (แก้ AUTH_SECRET เป็นค่าสุ่มจริงก่อนใช้งานจริง)
docker compose up --build
```

เปิดเบราว์เซอร์ที่ **http://localhost:3000**
ตอนเริ่ม container แอปจะสร้างตาราง (`prisma db push`) และ seed บัญชีตัวอย่างให้อัตโนมัติ

## 🌐 เปิดใช้งานจริงผ่าน Cloudflare Tunnel (HTTPS)
จำเป็นต้องเป็น **https** กล้อง/GPS บนมือถือจึงจะทำงาน (บน localhost ก็ได้สำหรับทดสอบ)

1. ใส่ `CLOUDFLARE_TUNNEL_TOKEN` ใน `.env` → `docker compose up -d` (service `cloudflared` จะต่อ tunnel ให้)
2. ใน **Cloudflare Zero Trust → Networks → Tunnels → (tunnel) → Public Hostname** ตั้ง:
   - Domain: โดเมนจริงของคุณ (เช่น `inspect.yourdomain.com`)
   - **Service: `HTTP://app:3000`** ← ต้องเป็นแบบนี้ (ไม่ใช่ localhost) ไม่งั้นขึ้น 502
3. แอปใช้ **auto-detect host** (ไม่ตั้ง `AUTH_URL`) + `AUTH_TRUST_HOST=true` จึงล็อกอินผ่านโดเมนได้เลย
4. พอร์ต Adminer (8080) ปิดไม่ให้เข้าจากภายนอก (เข้าได้เฉพาะใน docker network)

> ⚠️ tunnel รันอยู่บนเครื่องที่ลง Docker — ถ้าเครื่องปิด/sleep เว็บจะเข้าไม่ได้; ใช้งานจริง 24 ชม. ควรรันบนเซิร์ฟเวอร์ที่เปิดตลอด

## ⚙️ ตั้งค่า (`.env`)
| ตัวแปร | ความหมาย |
|--------|----------|
| `DATABASE_URL` | การเชื่อมต่อ Postgres |
| `AUTH_SECRET` | กุญแจเข้ารหัส session (ต้องสุ่มใหม่ก่อนใช้จริง) |
| `AUTH_TRUST_HOST` | `true` เพื่อให้ Auth.js อ่าน host จาก Cloudflare |
| `CLOUDFLARE_TUNNEL_TOKEN` | token ของ tunnel |
| `CHECKIN_MAX_ACCURACY_M` | เกณฑ์ความแม่นยำ GPS สูงสุด (เมตร), ค่าเริ่ม 50 |
| `CHECKIN_SESSION_TTL_MIN` | อายุรหัสเซสชันเช็คอิน (นาที), ค่าเริ่ม 5 |
| `SEED_ADMIN_USERNAME` / `SEED_ADMIN_PASSWORD` | บัญชี admin เริ่มต้น |

## 📁 โครงสร้างหลัก
```
src/app/
  login/ · register/          # เข้าสู่ระบบ / สมัครสมาชิก
  staff/                      # งานวันนี้, เช็คอิน, ส่งงาน, ประวัติ
  inspector/                  # คิวตรวจ + หน้าตรวจ (อนุมัติ 2 แบบ)
  admin/                      # dashboard, sites, checkpoints(+QR), assignments, reports, suspicious, users
  api/                        # auth, checkin(+session), submit, review(+onsite/session), register, files
src/components/               # QrScanner, GpsButton, PhotoInput, LocationPicker, StatCard, ฯลฯ
src/lib/                      # db, auth, session, storage, geo (Haversine), verify (กันโกง), date
prisma/schema.prisma          # User, Site, Checkpoint, Assignment, WorkRecord, Review, CheckInSession
```

## 🗓️ การเก็บเวลา
ทุกขั้นบันทึกเวลา: **เช็คอิน (`checkInAt`) → ส่งงาน (`submittedAt`) → อนุมัติ (`reviewedAt`)** — นำไปคำนวณ “เวลาที่ใช้ทำงาน” ในหน้ารายงาน
